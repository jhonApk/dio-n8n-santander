# n8n do Básico ao Avançado

## 1. Tema e objetivo

**Tema:** n8n do Básico ao Avançado.

**Objetivo:** Aprender a utilizar o n8n para criar automações de processos, integrar diferentes ferramentas e serviços, desenvolver workflows e explorar recursos avançados, incluindo agentes de inteligência artificial. O objetivo é reunir informações confiáveis e organizadas para facilitar o aprendizado, desde os primeiros passos até aplicações mais complexas.
